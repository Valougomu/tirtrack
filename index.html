Comment fonctionne la progression ?

Les XP sont attribués à l’enregistrement d’une séance et à quelques jalons de suivi. Aucun bonus n’est lié à la puissance, à la cadence ou à une prise de risque. Les missions sont des repères personnels et ne remplacent pas les règles du club.

Vos données

Les informations de séance sont enregistrées localement ; les photos sont conservées dans IndexedDB de ce navigateur. Les scores bruts sont conservés avec leur barème et normalisés sur 100 pour les graphiques ; cela ne garantit pas la comparabilité entre disciplines. Elles ne sont pas synchronisées entre appareils : exportez régulièrement une sauvegarde JSON.

Conseil : exportez un fichier JSON avant de changer de navigateur ou d’appareil. Le CSV est pratique pour analyser vos séances dans un tableur ; il ne contient pas les photos.
V28 · Les photos sont stockées dans IndexedDB sont redimensionnées et compressées avant sauvegarde. Les anciennes photos volumineuses peuvent être optimisées automatiquement. La compression réduit le poids mais ne rend pas le stockage illimité : gardez une sauvegarde JSON.

Confidentialité et données — V27

Cette version fonctionne principalement dans votre navigateur. Les informations ci-dessous décrivent le comportement du fichier local ; les journaux et traitements du service d’hébergement, si vous utilisez une version publiée, dépendent aussi de cet hébergeur.

Données conservées localementSéances, scores, notes, photos importées, profil local et préférences peuvent être enregistrés dans le stockage de ce navigateur.
Pas de synchronisation intégréeLes données ne suivent pas automatiquement l’utilisateur vers un autre navigateur ou appareil. Utilisez une sauvegarde exportée pour les transférer.
Profil local ≠ compte sécuriséLe nom et l’adresse e-mail saisis dans le profil sont stockés localement. Aucun mécanisme d’authentification serveur n’est fourni par ce prototype.
Export et effacementLe JSON peut contenir les données et les photos. Gardez-le dans un endroit sûr. L’effacement local supprime les données applicatives de ce navigateur, mais pas les copies exportées.

Avant une publication, l’éditeur doit compléter les coordonnées de contact, les finalités, les durées de conservation, les prestataires éventuels et la politique de confidentialité correspondant au déploiement réel. Cette notice n’est pas une certification de conformité RGPD.

Confidentialité : les photos de cible et les notes restent dans ce navigateur. Évitez d’ajouter des données personnelles inutiles. Une future version en ligne devra intégrer un compte sécurisé, une politique de confidentialité et une synchronisation protégée.
